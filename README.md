## Featured open-source work

### 🖥️ [Pironman 5 — Home Assistant Integration](https://github.com/ChristophKomenda/pironman5-homeassistant-container)

**Python · Home Assistant · HACS · REST API · Raspberry Pi · Docker**

I develop and maintain a **fully local Home Assistant integration** for the SunFounder Pironman 5 family. It provides native system monitoring and compatible hardware controls using SunFounder's existing REST API — **no MQTT broker, cloud account, or additional service required**.

**Highlights**
- **Accepted into the official HACS default repository** for easy installation and updates.
- Native monitoring for CPU, GPU, memory, network, and dynamically discovered NVMe, USB, and microSD storage.
- Compatible fan, RGB lighting, and OLED controls, with capability-aware entity setup.
- **v1.4.0:** Extended hardware diagnostics, network-interface IP sensors, read-only RGB LED count, and improved model/capability reporting.
- Multiple devices in one Home Assistant instance; 76 Python tests plus successful HACS and Hassfest checks for v1.4.0.
- **Real-device validation:** Two Pironman 5 Max systems, with 18 registered and active network IP diagnostic sensors across both devices. The new sensor values were also observed in Home Assistant.

**Compatibility note:** Pironman 5 Pro Max model recognition and future-feature readiness are implemented, but **Pro Max hardware compatibility has not yet been verified**.

[Repository & installation](https://github.com/ChristophKomenda/pironman5-homeassistant-container) · [v1.4.0 release](https://github.com/ChristophKomenda/pironman5-homeassistant-container/releases/tag/v1.4.0) · [HACS acceptance](https://github.com/hacs/default/pull/12242) · [Hardware test matrix](https://github.com/ChristophKomenda/pironman5-homeassistant-container/blob/main/docs/hardware-testing.md)
