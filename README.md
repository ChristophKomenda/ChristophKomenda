## Open Source

### SunFounder Pironman 5 / 5 Max

**Home Assistant Integration**

Developed a local Home Assistant integration for the SunFounder Pironman 5 and Pironman 5 Max, providing monitoring, fan, RGB and OLED control through the local Pironman REST API.

→ https://github.com/ChristophKomenda/pironman5-homeassistant

**Upstream contributions**

While working with the Pironman software, I contributed fixes and compatibility improvements directly to the upstream project.

* **OLED font asset path fix** — fixed an incorrect font path in the SSD1306 driver. Tested on Raspberry Pi 5 / Pironman 5 Max V2 / Debian Trixie and merged by SunFounder into their official `v2` branch. Classified as a **C-level fix**.
  → https://github.com/sunfounder/pm_auto/pull/19

* **Debian Trixie compatibility** — tested Pironman 5 Max on Debian Trixie (64 bit) and added the configuration to SunFounder’s official tested compatibility list.
  → https://github.com/sunfounder/pironman5/pull/109
